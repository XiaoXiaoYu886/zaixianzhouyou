## 「桌游玩家」在线桌游平台详细介绍

---

### 📌 项目定位

一款**无需下载、即开即玩**的在线桌游平台，支持多人实时联机对战经典桌游，让玩家通过浏览器即可与朋友共享游戏乐趣。

---

### 🎮 核心功能

**1. 用户系统**
- 邮箱注册 / 登录 / 登出
- 个人中心：查看头像、用户名、注册时间
- 战绩统计：总场次、胜率、总积分

**2. 房间系统**
- 创建房间：选择游戏类型（飞行棋/二十一点）、设置最大玩家数
- 加入房间：输入房间码快速加入 / 从房间列表选择
- 房主权限：房主可踢出玩家、开始游戏

**3. 实时联机**
- WebSocket 双向通信，实时同步：
  - 玩家进出房间状态
  - 游戏状态（回合、骰子结果、出牌等）
  - 房间内聊天消息
- 掉线检测与重连机制

**4. 游戏内容**

| 游戏 | 人数 | 玩法简介 |
|-----|-----|---------|
| 🎲 **飞行棋** | 2-4人 | 掷骰子决定移动，6点出发，撞到对手棋子将其打回起点，最先让4颗棋子全部到达终点者获胜 |
| 🃏 **二十一点** | 2-6人 | 下注后发牌，可选择要牌或停牌，点数最接近21点且不爆牌者获胜 |

---

### 🛠 技术架构

```
前端框架    Next.js 16 (App Router) + React 19
开发语言    TypeScript 5（全程类型安全）
样式方案    Tailwind CSS 4 + shadcn/ui 组件库
实时通信    WebSocket (ws) 长连接
后端认证    Supabase Auth（邮箱 + 密码）
数据存储    Supabase PostgreSQL + localStorage 演示模式
```

---

### ✨ 项目特色

**1. 演示模式**
- 未配置 Supabase 时自动启用本地存储模拟认证
- 用户可立即体验完整的注册登录流程
- 配置数据库后无缝切换为生产模式

**2. 防止作弊设计**
- 游戏核心逻辑在服务端计算
- 客户端仅负责状态渲染与用户输入
- WebSocket 消息签名校验

**3. 用户体验**
- 深色渐变背景 + 毛玻璃卡片设计
- 流畅的加载状态与错误提示
- 响应式布局适配桌面端与移动端

---

### 📊 数据模型

```
用户 (profiles) ──┬── 房间 (rooms)
                  │        │
                  │        └── 玩家-房间关系 (room_players)
                  │                  │
                  │                  └── 游戏记录 (game_records)
                  │
                  └── 聊天记录 (chat_messages)
```

---

### 🚀 部署与访问

- **开发地址**：http://localhost:5000
- **生产构建**：pnpm build && pnpm start
- **代码规范**：ESLint + TypeScript strict 模式
